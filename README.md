# Credit Scoring API (DataOps, ДЗ 3)

REST API для оценки кредитного риска заёмщика на базе FastAPI.

**ДЗ 6 (Инфраструктура как код):** развёртывание через [Terraform](terraform/) и [Ansible](ansible/) — см. [docs/HW6-README.md](docs/HW6-README.md). Вариант 2: используется заглушка (dummy model), имитирующая поведение модели скоринга.

---

## Клиентский путь (User Story)

**Кто:** Кредитный аналитик в банке.

**Как:** Аналитик заполняет анкету клиента в CRM-системе. После нажатия кнопки «Рассчитать скоринг» CRM отправляет данные на наш API и получает в ответ оценку кредитного риска, которая отображается на экране.

**Результат:** Аналитик видит предсказание (низкий/высокий риск) и скоринговый балл для принятия решения по заявке.

---

## Функциональные требования

1. Сервис принимает на вход JSON со структурой:
   - `age` — целое число (возраст),
   - `income` — число с плавающей точкой (доход),
   - `months_on_book` — целое число (срок в месяцах как клиент банка),
   - `credit_limit` — число с плавающей точкой (кредитный лимит).

2. Сервис возвращает JSON с полями:
   - `prediction` — строка (`"low_risk"` или `"high_risk"`),
   - `score` — число от 0 до 1 (скоринговый балл).

3. При отсутствии обязательных полей или неверных типах данных сервис возвращает ошибку **422 Unprocessable Entity**.

4. Эндпоинт **GET /health** всегда возвращает `{"status": "ok"}` для проверки работоспособности сервиса.

## Описание эндпоинта

### POST /predict — расчёт скоринга

| Параметр   | Значение |
|-----------|----------|
| **Метод** | POST     |
| **URL**   | `/predict` |

**Пример тела запроса (Request Body):**

```json
{
  "age": 35,
  "income": 60000.0,
  "months_on_book": 24,
  "credit_limit": 50000.0
}
```

**Пример успешного ответа (200 OK):**

```json
{
  "prediction": "low_risk",
  "score": 0.8523
}
```

**Пример ответа с ошибкой (422 Unprocessable Entity):**

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "credit_limit"],
      "msg": "Field required"
    }
  ]
}
```

### GET /health — проверка состояния сервиса

**Пример успешного ответа (200 OK):**

```json
{
  "status": "ok"
}
```

## Запуск проекта

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск сервера

```bash
uvicorn app.main:app --reload
```

Сервер будет доступен по адресу http://127.0.0.1:8000. Интерактивная документация — http://127.0.0.1:8000/docs.

### Запуск тестов

```bash
pytest tests/ -v
```
